# Contributing

Thanks for your interest in contributing to this project.

## How to contribute

1. Fork the repository and create your feature branch.
2. Make your changes in a focused, clearly described commit.
3. Run the relevant validation or tests for your change.
4. Open a pull request using the repository's pull request template.

## Code guidelines

- Keep changes small and focused.
- Write clear commit messages.
- Include tests where appropriate.
- Update documentation if behavior or setup changes.

## Reporting issues

Before opening a new issue, please check whether a similar issue already exists.

## Pull requests

Provide a brief summary of what changed and why. Include testing details and any follow-up items if needed.

## Questions

If you are unsure about anything, open an issue and ask for guidance.
